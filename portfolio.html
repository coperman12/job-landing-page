02

Digital Face, a watch face for Garmin

Embedded · Monkey C · 2026

A configurable watch face for 41 round AMOLED Garmin models, built from scratch on the Connect IQ SDK.

  • 4 layouts, 6 data slots and 15 metrics to choose from: heart rate, stress, Body Battery, steps and more.

03

RepoAsk, ask a GitHub repository anything

AI · RAG · Full stack · 2026

A web app that answers questions about a private GitHub repository in natural language, and shows the exact code each answer relies on.

  • RAG pipeline: files are split into chunks with line ranges, embedded, and stored in PostgreSQL with pgvector for similarity search.
  • Answers cite their sources, with links to the exact lines on GitHub. A question with no support in the code gets "not found", not a guess.
  • A semantic cache over the question history: a rephrased question is answered in under 0.1 seconds instead of about 4, plus related and popular questions.
  • Sign-in with per-user access to chosen repositories, login and daily-question limits, a read-only GitHub token, and Docker deployment.
  • Documented like a real project: architecture diagram, 7 user stories, a requirements spec, and 25 automated tests.
  • .NET 9 Minimal API
  • React 19
  • TypeScript
  • PostgreSQL
  • pgvector
  • Docker
  • Claude API
  • Ollama
  • xUnit

The code is in a private repository. A live demo and a walkthrough of the architecture are available on request.

Accessibility statement

This site is built with the goal of meeting WCAG 2.1 level AA, the basis of Israeli Standard 5568. It uses semantic HTML for screen readers, works with a keyboard, and offers this menu for adjusting colors, text, motion and read aloud. It has not gone through a formal external accessibility audit, so some issues may remain.

If you run into an accessibility problem, please tell me through the contact form or on LinkedIn, and I will fix it as soon as I can.
